# Model Card: AISpeechGenerator

## Цель модели

**Бизнес-задача:** Предоставление API для автоматической генерации структурированных речей (вступление, основная часть, заключение) на русском языке.

**Основная функция:** Преобразование входных параметров (тема, длительность, ключевые моменты, стиль) в готовый текст выступления.

**Целевая аудитория:** Спикеры, преподаватели, студенты, создатели контента, которым требуется быстрая подготовка черновиков речей.

**Интеграция:** REST API на базе FastAPI для встраивания в сторонние приложения.

## Метрики

Поскольку модель не обучалась с нуля в рамках проекта, метрики оценивают качество генерации в рамках конкретных задач (task-specific evaluation):

- **Соответствие стилю:** Оценка соответствия тональности выбранному стилю (научный, вдохновляющий, разговорный). Оценивается экспертно или через LLM-as-a-judge.
- **Удержание ключевых моментов:** Процент ключевых тезисов из запроса, которые были раскрыты в тексте. Целевое значение: более 90%.
- **Читабельность:** Соответствие грамматике русского языка и оценка связности.

## Ограничения

- **Размер контекста:** Модель Phi-3-mini имеет контекстное окно 4096 токенов. Это означает, что длинные речи (например, на 20+ минут) могут быть обрезаны или потребуют разбивки на части.
- **Язык:** Модель оптимизирована для английского языка. Генерация на русском возможна, но может уступать в стилистической точности и грамматике специализированным русскоязычным моделям.
- **Фактологичность:** Модель не имеет доступа к интернету и базе знаний в реальном времени. Она может генерировать правдоподобные, но ложные факты (галлюцинации).
- **Дата отсечки знаний:** Данные в модели актуальны по октябрь 2023 года. События после этой даты модели неизвестны.
- **Зависимость от промпта:** Качество результата сильно зависит от того, насколько корректно составлен системный промпт и переданы key_points. При плохом промпте результат будет поверхностным.
- **Аппаратные требования:** Для комфортной работы требуется 8+ GB RAM. Без CUDA-совместимой видеокарты генерация может быть медленной.

## Bias/Fairness анализ

- **Наследуемый bias:** Модель Phi-3-mini обучалась на больших массивах данных из интернета. Она может воспроизводить стереотипы, предвзятость и токсичность, присутствующие в обучающих данных.
- **Гендерные и культурные стереотипы:** При генерации речей на определенные темы (например, о профессиях) модель может непреднамеренно использовать гендерно-окрашенные формулировки.
- **Политическая предвзятость:** Возможен дисбаланс в освещении политических тем.

## Версия данных

- **Базовая модель:** microsoft/Phi-3-mini-4k-instruct
- **Датасет базовой модели:** 4.9 триллиона токенов. 
Состав обучающих данных
  - Отфильтрованные публичные данные: Качественно отобранные общедоступные документы, образовательные материалы и код.
  - Синтетические «учебные» данные: Данные, сгенерированные для обучения модели математике, программированию, логике и общим знаниям.
  - Данные для инструкций (Chat Format): Высококачественные диалоговые данные, которые учат модель следовать инструкциям, быть честной и полезной
- **Дата отсечки знаний базовой модели:** октябрь 2023 года.
- **Датасеты для дообучения:** Проект не выполняет fine-tuning. Используется zero-shot генерация через промпты.
- **Данные для промптов:** В проекте используются стили, хранящиеся в JSON (управляются через styles_api.py). Эти данные являются пользовательскими и не являются частью обучающей выборки модели.
